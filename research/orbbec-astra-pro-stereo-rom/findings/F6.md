# F6: Hybrid pipeline design

## Findings

### [1] The canonical RGB-D hybrid pipeline for 3D human pose estimation is "detect 2D from color, lift to 3D with depth" -- this architecture consistently outperforms both color-only and depth-only approaches
- quote: "We propose an approach to estimate 3D human pose in real world units from a single RGBD image and show that it exceeds performance of monocular 3D pose estimation approaches from color as well as pose estimation exclusively from depth. Our approach builds on robust human keypoint detectors for color images and incorporates depth for lifting into 3D."
- url: https://arxiv.org/abs/1803.02622
- source_type: primary
- published: 2018-03 (ICRA 2018)
- confidence: high

### [2] RGB-D fusion for 3D human pose can integrate color features with depth images via point-cloud-based dense prediction, regressing 3D keypoints directly from fused representations rather than simple depth lookup
- quote: "The color features are integrated with the depth image in the ... a method to regress 3D human keypoints from RGB-D images. To distinguish 2D detection error from 2D-to-3D lifting error."
- url: https://ieeexplore.ieee.org/abstract/document/9506588/
- source_type: primary
- published: 2021 (IEEE ICIP 2021)
- confidence: high

### [3] RTMW extends RTMPose to monocular 3D whole-body pose estimation via coordinate classification, using FPN + Hierarchical Encoding Module -- but it relies on learned depth priors from 2D images alone, not sensor depth
- quote: "We incorporate RTMPose model architecture with FPN and HEM (Hierarchical Encoding Module) to better capture pose information from different body parts with various scales... we explored the performance of RTMW in the task of 3D whole-body pose estimation, conducting image-based monocular 3D whole-body pose estimation in a coordinate classification manner."
- url: https://arxiv.org/abs/2407.08634
- source_type: primary
- published: 2024-07-11
- confidence: high

### [4] STA-TFM demonstrates that 2D pose estimators (including RTMPose) can serve as feature extractors feeding a fusion transformer that aggregates multi-view information to produce 3D estimates, achieving 50.9% MPJPE reduction on DHP19 by handling noisy and missing 2D inputs
- quote: "The approach leverages DSTformer, a monocular feature extractor, to capture long-range pose dependencies within each view. A fusion transformer then aggregates information across views to produce coherent 3D estimates. STA-TFM handles noisy and missing 2D inputs, supporting potential deployment in healthcare monitoring."
- url: https://arxiv.org/abs/2609.24482
- source_type: primary
- published: 2026-09-21
- confidence: high

### [5] Azure Kinect's superior depth sensor produced better point clouds and more accurate shoulder ROM estimation than Kinect v2, confirming that depth sensor quality directly impacts joint position estimation accuracy for clinical ROM
- quote: "point cloud, which leads to better results when we get better input data. The hardware superiority of Azure Kinect may have contributed to the accurate position estimation."
- url: https://www.sciencedirect.com/science/article/pii/S1058274622004347
- source_type: primary
- published: 2022 (J Shoulder Elbow Surg)
- confidence: high

### [6] Clinical shoulder ROM software (SRS) validated an RGB-D camera pipeline that constructs a textured point cloud from color + depth map to generate 3D joint references for ROM measurement, demonstrating the exact hybrid architecture relevant to our use case
- quote: "the medical community toward markerless (and all the more contactless) human pose estimation solutions ... map, to construct a textured point cloud that generated the image."
- url: https://link.springer.com/article/10.1007/s00264-022-05675-9
- source_type: primary
- published: 2023 (Int Orthop)
- confidence: high

### [7] Monocular HPE models for shoulder ROM achieved RMSE <10 degrees in 8 of 10 movements but suffered from perspective distortion and variable lighting -- adding depth data is the natural next step to address these limitations
- quote: "Challenges such as image perspective distortion, environmental lighting conditions, images in monocular view, and complications in the pose may influence the models' performance... HPE models show promise in identifying KJPs and facilitating ROM measurements... However, their current accuracy for this application is unsatisfactory."
- url: https://pmc.ncbi.nlm.nih.gov/articles/PMC11679233/
- source_type: primary
- published: 2024-12-14
- confidence: high

### [8] Occlusion of point cloud data around joints is the primary failure mode for depth-sensor-based pose estimation; the system works well when there is "little or no occlusion of the point cloud data surrounding the joint"
- quote: "is little or no occlusion of the point cloud data surrounding the joint. If ... pose estimation algorithm with correctly labelled shoulder joints that contain training data with elevated shoulders."
- url: https://www.sciencedirect.com/science/article/pii/S1386505618312759
- source_type: primary
- published: 2019 (Int J Med Inform)
- confidence: high

### [9] The end-to-end HPE deployment pipeline has 7 stages (acquisition, detection, localization, pose inference, tracking, smoothing, decoding) where each stage's failure mode becomes the next stage's corrupted input -- hybrid pipelines must handle this propagation
- quote: "HPE does not deploy as a network--it deploys as a pipeline... a production system integrates sensor acquisition, person detection, bounding-box localization, pose inference, multi-person tracking, temporal smoothing, coordinate decoding, and application-level post-processing into a sequential chain, where each stage's failure mode is the next stage's corrupted input."
- url: https://pmc.ncbi.nlm.nih.gov/articles/PMC13468773/
- source_type: primary
- published: 2026-07-28 (Sensors)
- confidence: high

### [10] Sinha et al. used depth-camera point clouds to estimate joint motion trajectories for rehabilitation, using depth-based point cloud processing around joint regions to extract 3D joint positions -- demonstrating depth-cloud-to-joint-position as a viable architecture path
- quote: "more expensive clinical gold standard motion capture devices ... The point cloud Pt corresponding to the depth frame at time t ... the shoulder joint during shoulder abduction."
- url: https://ieeexplore.ieee.org/abstract/document/8037700/
- source_type: primary
- published: 2017 (IEEE EMBC 2017)
- confidence: medium

### [11] A 2025 review specifically on shoulder ROM assessment identifies depth-sensor techniques alongside camera-based pose estimation as the two main technical approaches, and notes the emerging trend of combining them
- quote: "in assessments, the shoulder movements that are typically assessed in the clinical setting, the ... -based and depth sensor techniques commonly used for pose estimation in the literature."
- url: https://www.mdpi.com/1424-8220/25/3/667
- source_type: primary
- published: 2025 (Sensors)
- confidence: medium
