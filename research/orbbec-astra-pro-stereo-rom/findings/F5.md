# F5: Point cloud shoulder geometry

## Findings

### [1] PCL surface normal estimation uses PCA on k-nearest-neighbor covariance matrix, with curvature as the ratio of smallest eigenvalue to sum of all three eigenvalues.
- quote: "The solution for estimating the surface normal is reduced to an analysis of the eigenvectors and eigenvalues (or PCA - Principal Component Analysis) of a covariance matrix created from the nearest neighbors of the query point."
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/normal_estimation.html
- source_type: primary
- published: unknown (PCL 1.13+ docs)
- confidence: high

### [2] PCL provides NormalEstimationOMP as a drop-in multi-threaded replacement for single-threaded NormalEstimation; for organized (2.5D) point clouds from depth/stereo cameras, the even faster NormalEstimationUsingIntegralImages variant is recommended.
- quote: "If your dataset is organized (e.g., acquired using a TOF camera, stereo camera, etc - that is, it has a width and a height), for even faster results see the Normal Estimation Using Integral Images."
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/normal_estimation.html
- source_type: primary
- published: unknown
- confidence: high

### [3] PCL RANSAC plane segmentation via SACSegmentation with SACMODEL_PLANE and SAC_RANSAC outputs model coefficients in ax+by+cz+d=0 form plus inlier point indices, with a configurable distance threshold for inlier classification.
- quote: "create the SACSegmentation object and set the model and method type. This is also where we specify the 'distance threshold', which determines how close a point must be to the model in order to be considered an inlier."
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/planar_segmentation.html
- source_type: primary
- published: unknown
- confidence: high

### [4] PCL iterative multi-plane extraction uses VoxelGrid downsampling + repeated RANSAC plane segmentation + ExtractIndices to peel off planar surfaces from a scene, stopping when less than30% of points remain - a pattern directly applicable to separating torso plane from arm point clouds.
- quote: "Segment the largest planar component from the remaining cloud ... Extract the inliers ... While 30% of the original cloud is still there"
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/extract_indices.html
- source_type: primary
- published: unknown
- confidence: high

### [5] Open3D0.19.0 provides PointCloud.segment_plane(distance_threshold, ransac_n, num_iterations) which returns plane_model [a,b,c,d] and inlier indices using RANSAC, and estimate_normals() with KDTreeSearchParamKNN/Radius/Hybrid for normal estimation - all in Python with no C++ compilation required.
- quote: (from API reference) "segment_plane(distance_threshold=0.01, ransac_n=3, num_iterations=1000, probability=0.999) - Segment a plane in the point cloud using RANSAC."
- url: https://www.open3d.org/docs/release/python_api/open3d.geometry.PointCloud.html#open3d.geometry.PointCloud.segment_plane
- source_type: primary
- published: unknown (Open3D0.19.0)
- confidence: high

### [6] A comprehensive review (Xu et al.,2021, Sensors) covering point-cloud-based3D human joint estimation from depth cameras found that3D point cloud meshing was used to estimate the3D shoulder joint center, and depth cameras provide ranging information from a single depth image or a point cloud for joint estimation.
- quote: "depth camera can provide the ranging information from a single depth image or a point cloud ... the3D information of the point cloud was meshed to estimate the3D shoulder"
- url: https://www.mdpi.com/1424-8220/21/5/1684
- source_type: secondary (peer-reviewed review article)
- published:2021
- confidence: high

### [7] Jatesiktat et al. (2018, NTU) proposed personalized markerless upper-body tracking using a depth camera that computes3D joint center positions from3D point cloud and body silhouette, achieving improved shoulder tracking by fitting a personalized human mesh model to depth data.
- quote: "3D point cloud, the body silhouette, and the 3D joint positions ... The detailed calculations of joint center calculation are ..."
- url: https://dr.ntu.edu.sg/entities/publication/c0d390e7-8945-439a-9b30-24afdb6b2ce2
- source_type: secondary (peer-reviewed,20 citations)
- published:2018
- confidence: high

### [8] Abromavicius et al. (2026, IEEE Sensors) demonstrated calibration-free shoulder kinematics using single and dual asynchronous RGB-D cameras, using sparse point cloud measurements with signed distance fields to estimate shoulder joint angular trajectories (alpha, beta, gamma).
- quote: "Depth sensors utilize sparse point cloud measurements with signed distance fields ... angular trajectories (alpha, beta, gamma) of the shoulder joint estimated during five ..."
- url: https://ieeexplore.ieee.org/abstract/document/11368759/
- source_type: secondary (peer-reviewed, IEEE,3 citations)
- published:2026
- confidence: high

### [9] Rozevink et al. (2018, 3DBODY.TECH) proposed a new method for finding the shoulder complex rotation center using3D body scanning, running RANSAC250 times per point cloud to robustly estimate the rotation center from marker points embedded in the point cloud model.
- quote: "250 times per point cloud to provide a robust estimate."
- url: https://www.academia.edu/download/77108226/18019rozevink.pdf
- source_type: secondary (peer-reviewed conference)
- published:2018
- confidence: medium

### [10] Normal orientation consistency for depth-camera point clouds can be achieved in PCL by flipping normals toward the known viewpoint using flipNormalTowardsViewpoint() - critical for shoulder surface analysis where consistent outward-facing normals are needed for curvature and glenoid plane detection.
- quote: "To orient all normals consistently towards the viewpoint, they need to satisfy the equation: n_i . (v_p - p_i) > 0"
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/normal_estimation.html
- source_type: primary
- published: unknown
- confidence: high

### [11] PCL normal estimation scale selection is critical: too small radius/k captures noise; too large smears edges between surfaces (e.g., between torso and arm) - for shoulder geometry at typical depth camera ranges (0.5-2m), a radius of0.01-0.05m is a reasonable starting point.
- quote: "if the curvature at the edge between the handle of a mug and the cylindrical part is important, the scale factor needs to be small enough to capture those details"
- url: https://pcl.readthedocs.io/projects/tutorials/en/latest/normal_estimation.html
- source_type: primary
- published: unknown
- confidence: medium
