# F1: Orbbec Astra Pro hardware & SDK

## Findings

### [1] The Astra series (including Astra Pro Plus) uses structured light depth technology with an 850nm infrared projector and Orbbec-designed ASIC for on-device depth processing.
- quote: "Depth Technology: Structured Light ... Wavelength: 850nm ... Processing: Orbbec ASIC"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown (page still active as of 2026)
- confidence: high

### [2] The Astra Pro Plus has a depth range of 0.6-8m with a precision of plus/minus 3mm at 1m, and depth resolution up to 640x480 at 30 fps.
- quote: "Depth Range: *0.6-8m ... Precision: +/-3mm @ 1m ... Depth Resolution/FPS: Up to 640X480@30fps"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown
- confidence: high

### [3] The Astra Pro Plus supports RGB resolution up to 1920x1080 at 30 fps, with an RGB FOV of H66.1 degrees x V40.2 degrees, versus the standard Astra's 640x480 RGB at 30 fps with FOV H63.1 degrees x V49.4 degrees.
- quote: "RGB Resolution/FPS: Up to 1920X1080@30fps (Pro Plus), 640X480@30fps ... RGB FOV: H66.1 degrees V40.2 degrees (Pro Plus), H63.1 degrees V49.4 degrees"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown
- confidence: high

### [4] The Astra series connects via USB 2.0 Type-A for both power and data, consuming an average of less than 2.4W, with a depth FOV of H58.4 degrees x V45.5 degrees. The camera is rated for indoor use at 10-40 degrees C, 10-85% RH.
- quote: "Data Connection: USB 2.0 Type-A ... Power Input: USB 2.0 Type-A ... Power Consumption: Average <2.4W ... Depth FOV: H58.4 degrees V45.5 degrees ... Operating Environment: 10 C - 40 C; Indoor; 10%-85%RH"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown
- confidence: high

### [5] The Astra Pro Plus is supported by Orbbec OpenNI SDK (latest v2.3.0.86) on Linux (Ubuntu 14.04+), Windows (10+), and Android (4.4.2+), as well as ROS and ROS2 wrappers via the OpenNI2 protocol.
- quote: "Supports Astra Series, Astra Mini (S), Astra Mini Pro, Astra Stereo S U3, Astra Embedded S, Gemini E" ... "Ubuntu 14.04 or later ... USB 2.0+ ... Duo Core 1.8GHz+ ... 1GB+ RAM"
- url: https://www.orbbec.com/developers/openni-sdk/
- source_type: primary
- published: unknown (SDK version 2.3.0.86)
- confidence: high

### [6] In Orbbec SDK v1 (v1.10.37), the Astra Pro Plus has "limited maintenance" support (critical bug fixes only), and is "not supported" in Orbbec SDK v2. This means the Astra Pro Plus is a legacy product on the OpenNI protocol that will not receive new features.
- quote: "Astra Pro Plus ... Orbbec SDK v1: limited maintenance ... Orbbec SDK v2: not supported"
- url: https://github.com/orbbec/OrbbecSDK
- source_type: primary
- published: unknown (repo active, 230 commits)
- confidence: high

### [7] Orbbec SDK v1 (the version that supports Astra Pro Plus) explicitly supports Linux ARM64 on Ubuntu 18.04/20.04/22.04 with GCC 7.5, including NVIDIA Jetson AGX Orin, Orin NX, Orin Nano, AGX Xavier, Xavier NX, Jetson Nano, A311D, Raspberry Pi 4, and RK3399.
- quote: "Arm64 - Linux Ubuntu 18.04/20.04/22.04 ... Support GCC 7.5 ... supported Arm platforms: NVIDIA Jetson AGX Orin (arm64), NVIDIA Jetson Orin NX (arm64), NVIDIA Jetson Orin Nano (arm64), NVIDIA Jetson AGX Xavier (arm64), NVIDIA Jetson Xavier NX (arm64), NVIDIA Jetson Nano (arm64), A311D (arm64), Raspberry Pi 4 (arm64), Raspberry Pi 3 (arm32), RK3399 (arm64)"
- url: https://github.com/orbbec/OrbbecSDK
- source_type: primary
- published: unknown
- confidence: high

### [8] The Astra Pro Plus data output includes Point Cloud, Depth Map, IR, and RGB streams. The ROS wrapper (ros_astra_camera, 131 stars) supports point cloud publishing (XYZ and XYZRGB), depth-to-color alignment, and multi-camera setups via OpenNI2.
- quote: "Data Output: Point Cloud, Depth Map, IR or RGB" ... "enable_point_cloud: Whether to enable point cloud ... enable_point_cloud_xyzrgb: Whether to enable RGB point cloud ... depth_align: Enables hardware depth to color alignment"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/ and https://github.com/orbbec/ros_astra_camera
- source_type: primary
- published: unknown
- confidence: high

### [9] The Astra Pro Plus dimensions are 165mm x 48mm x 40mm, weighs 310g, and has an M6 mounting point on the bottom. It has no IMU.
- quote: "Dimensions (W*H*D): 165mm x 48mm x 40mm ... Weight: 310g ... Installation: Bottom: M6 ... IMU: N/A"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown
- confidence: high

### [10] The Astra Mini Pro (short-range variant) has a depth range of 0.4-2m, while the standard Astra has 0.6-8m. For a shoulder ROM application at typical clinic distances (0.5-2m), the Astra Mini S variant's shorter range may provide better close-range accuracy, but the standard Astra Pro Plus at 0.6-8m covers typical operating distances.
- quote: "Depth Range: *0.6-8m, 0.4-2m (S)"
- url: https://www.orbbec.com/products/structured-light-camera/astra-series/
- source_type: primary
- published: unknown
- confidence: medium

### [11] The Orbbec SDK v1 provides a CMake-based build system with pre-compiled libraries for Linux x64 and ARM64, C/C++ headers, and examples. It includes udev rules scripts for Linux to resolve USB permission issues without root.
- quote: "Linux udev rules for resolving permission issues" ... "cd OrbbecSDK/misc/scripts && sudo chmod +x ./install_udev_rules.sh && sudo ./install_udev_rules.sh"
- url: https://github.com/orbbec/OrbbecSDK
- source_type: primary
- published: unknown
- confidence: high
